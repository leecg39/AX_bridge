# AX브릿지 · 로컬 검토용 MVP 1.2.0

2026-10-05: 현재 폴더의 1.0.0을 기반으로 AX-QA F01~F09를 수정하고, 견적 공유 승인·추천인 기록·상담 접수를 추가했습니다. [반영 내역](docs/QA-IMPLEMENTATION.ko.md)과 [현재 검증 결과](docs/VERIFICATION.ko.md)를 확인하세요.

AX 구축, 외부 AI 교육, AI 인프라 장비 공급을 중개하는 업무를 한곳에서 검토하는 소스 패키지입니다. 상담·영업 CRM → 견적 비교 → 공급사 선택 → 납품·검수 → 완료의 흐름을 SQLite에 저장합니다.

**이 버전은 로컬 시연용입니다. 실제 서비스 가입·로그인·고객별 보안 경계가 없습니다. 인터넷, 공유 네트워크, 터널 또는 역방향 프록시로 공개하지 마세요. 실제 고객의 민감정보·비밀번호·결제정보는 입력하지 마세요.**

`AX브릿지`는 검토용 가칭이며 상표·도메인 사용 가능 여부를 확인한 이름이 아닙니다.

참고 방향은 [SourcePanel](https://www.sourcepanel.com/)의 요구 정리·공급 연결·마일스톤 운영, [AIonDemand](https://www.aiodp.ai/)의 솔루션·교육·인프라 분류, [Thumbtack](https://www.thumbtack.com/)의 단순 입력 흐름입니다. 브랜드나 화면을 복제하지 않았으며, SourcePanel의 no-bidding 방식과 이 MVP의 다중 견적 비교는 같은 사업 모델이 아닙니다.

## 1. 빠른 시작

필요한 환경은 **Node.js 24 이상**과 최신 데스크톱 브라우저입니다. Node 내장 HTTP 서버·SQLite를 사용하며 npm 외부 의존성이 없습니다. 별도의 `npm install`은 필요하지 않습니다.

1. 소스 ZIP을 자신의 컴퓨터 또는 검토용 VM에 풉니다.
2. 터미널에서 압축을 푼 폴더로 이동합니다.
3. 아래 명령으로 버전을 확인하고 실행합니다.

```sh
node --version
npm start
```

4. **서버를 실행한 컴퓨터/VM 안의 브라우저**에서 [http://127.0.0.1:4318](http://127.0.0.1:4318)을 엽니다. 서비스 홈이 표시되며, 운영실은 [관리자 화면](http://127.0.0.1:4318/admin.html)에서 이용합니다.
5. 종료할 때는 서버 터미널에서 `Ctrl+C`를 누릅니다.

구조와 스타일만 먼저 보고 싶다면 [PREVIEW.html](PREVIEW.html)을 파일로 열 수 있습니다. 관리자 화면의 정적 HTML 미리보기로 일부 메뉴 이동만 가능하며, 등록·수정·저장·수요/공급 포털 기능은 서버 실행이 필요합니다. 실제 브라우저 스크린샷이나 시각 검수 결과물이 아닙니다.

VM에서 실행했다면 호스트 컴퓨터의 `127.0.0.1`은 그 VM이 아닙니다. 이 패키지는 VM 내부 브라우저로 확인하는 로컬 검토를 전제로 합니다. 외부 접속을 위해 `0.0.0.0`으로 바꾸거나 포트 공개를 하지 마세요.

### 실행 설정

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `4318` | 사용 중인 경우 다른 로컬 포트 지정 가능 |
| `HOST` | `127.0.0.1` | `127.0.0.1`, `localhost`, `::1`만 허용 |
| `DATA_DIR` | 프로젝트의 `data/` | SQLite 파일을 둘 경로. 쓰기 권한 필요 |

예를 들어 macOS/Linux에서는 `PORT=4320 npm start`로 바꿀 수 있습니다. 실행 로그에 표시된 주소를 사용하세요. `node:sqlite` 관련 경고가 표시되는 Node 버전에서는 오류와 경고를 구별하고 서버 시작 로그를 확인하세요.

### 세 가지 중개 업무

- **AX 구축:** 문제·요구사항·성공 기준과 구축 범위, 비용, 운영 조건 비교
- **AI 교육:** 외부 교육업체를 연결하는 중개 모델. 대상·인원·수준·목표·주제·방식·장소·시간과 공급사의 커리큘럼·실습·강사·교육 후 지원 기록
- **AI 인프라:** 서버·장비 공급 중개 모델. 도입 목적·기존 환경·설치 장소와 공급사의 사양·수량·설치비·납기·보증 기록. 설치비는 견적 총액에 포함된 항목으로 표시

견적 선택, 지원사업의 신청 상태 변경, 투자 결정 상태는 모두 **내부 기록**입니다. 실제 계약, 기관 신청, 외부 연락, 투자 거래 또는 결제를 실행하지 않습니다.

## 3. 데모 데이터와 사실 확인

- 샘플 고객사·담당자·프로젝트·교육 강사·견적 금액·납품 조건·투자 후보는 가상입니다.
- 르몽은 공급사 후보이며 실제 협업 확정 상태가 아닙니다.
- 어크로스는 GEO 직접 공급 후보 맥락과 이재홍 담당자 메모를 반영했습니다. 법인, 제공 범위, 연락처, 계약 및 가격 검증을 대신하지 않습니다.
- 스파르타·에이블런·세계경영연구회는 협업 논의 중인 AI 교육 후보입니다. 체결된 제휴가 아니며 정확한 법인명·상품·과정·가격은 확인되지 않았습니다.
- `협업 확인`, `공식 출처 확인`, `선정 기록` 등은 사용자가 입력하는 상태입니다. 시스템이 실사를 수행하거나 사실을 보증하지 않습니다.
- 지원사업의 **정책·예산 발표와 실제 개별 모집 공고는 구분**해야 합니다. 사업에 기록된 공식 원문과 확인 메모를 읽고, 해당 연도의 접수 상태·대상 요건·자부담·수정 공고를 다시 확인하세요. 예산 발표만으로 현재 신청 가능하다고 판단하면 안 됩니다.
- 미검증 또는 가상 지원사업은 기능 검토용입니다. 실제 공고가 기록되어 있어도 자동 갱신·자격 판정·선정 예측 기능은 없습니다.
- 첫 실행과 시연 데이터 초기화 시 샘플 일정은 실행 시점 기준으로 생성됩니다. 일부 지난 기한은 알림 표시를 검토하기 위한 의도적인 예시입니다. 이미 저장한 일정은 재시작만으로 바뀌지 않습니다.

## 4. 저장·백업·복원

기본 저장 파일은 `data/ax-broker.sqlite`입니다. 같은 데이터 폴더로 재실행하면 기록이 유지됩니다. 빈 데이터로 정상 가져오기한 경우에도 다음 실행 시 샘플을 다시 채우지 않습니다.

1. 관리자 **데이터 관리 → JSON 백업 받기**를 선택합니다.
2. 내려받은 JSON 파일을 별도 안전한 위치에 보관합니다.
3. 복원할 때 **백업 불러오기**에서 해당 파일을 선택하고 전체 교체 내용을 확인합니다.

백업은 프로젝트·공급사·견적·마일스톤·할 일뿐 아니라 **영업자·상담활동·지원사업·신청 기록·투자 검토를 모두 포함**합니다. 가져오기는 병합이 아니라 전체 교체입니다. 형식·참조 무결성 검증을 통과한 데이터를 한 트랜잭션으로 반영합니다. 현재 UI/API는 약 1MB 크기의 요청 제한이 있으므로 큰 백업은 가져올 수 없습니다.

**초기화·가져오기 전에 반드시 기존 JSON 백업을 받으세요. 자동 백업, 휴지통, 변경 이력 복구는 없습니다.** 백업 JSON은 암호화되지 않은 전체 데이터입니다. 다른 사람이나 서비스에 보내지 말고 로컬 검토 파일로 취급하세요.

SQLite가 실행 중이면 `-wal`, `-shm` 보조 파일이 생길 수 있습니다. 실행 중인 데이터베이스 본체만 복사하지 말고 JSON 내보내기를 사용하세요. 파일 단위 보관이 필요하면 서버를 정상 종료한 뒤 데이터 폴더를 함께 보관합니다.

## 5. 보안 한계와 운영 제외 범위

`X-Demo-Role`과 `X-Demo-Entity` 헤더는 클라이언트가 자유롭게 바꿀 수 있습니다. 서버는 선택한 역할에 맞춰 응답과 수정 필드를 제한하지만, **인증된 사용자의 권한을 확인하는 구조가 아닙니다. 서버에 접근한 사람은 누구나 관리자 역할을 선택할 수 있습니다.** 헤더가 없으면 관리자 데모 동작을 합니다.

검토용 가입은 비밀번호, 실제 계정, 이메일 인증, 직원 초대, 세션 또는 기업별 테넌트를 만들지 않습니다. 고객 정보는 독립 고객/담당자 테이블 대신 프로젝트 안에 저장합니다. 같은 회사의 여러 프로젝트를 하나의 정식 고객 마스터로 관리하는 기능은 후속 범위입니다.

포함하지 않는 기능:

- 실사용자 인증·테넌트 격리·운영 감사로그·권한 승인
- 외부 이메일/메시지 발송, 전자계약·서명·결제·정산
- 실제 파일 첨부 저장, 클라우드 파일 권한 관리
- 실시간 다중 사용자 편집·충돌 해결·운영 자동 백업
- 지원사업 자동 수집·신청·자격 판정 또는 선정 보장
- 투자 추천 알고리즘·수익률 예측·투자자 공개 모집·계약·주문·송금
- 생산용 배포·TLS·보안 운영 체계

로컬 바인딩, Host/Origin 확인, 기본 보안 헤더, 입력 검증 등은 제한적인 방어 장치입니다. 이 기능들이 실서비스 수준의 보안 검증을 의미하지 않습니다.

## 7. 추가된 업무 흐름

1. 관리자 → 영업 CRM에서 추천코드와 가입 링크를 확인합니다. 새 영업자 등록 시 코드를 비우면 자동 생성됩니다.
2. 추천 링크로 가입하면 최초 추천인/코드와 현재 담당자가 기록됩니다. 담당자 변경은 최초 추천 기록을 바꾸지 않습니다.
3. 수요기업 가입 후 상담 요청서를 접수합니다. 같은 의뢰에서 재접수하면 기존 접수번호와 할 일을 유지하면서 내용만 갱신합니다.
4. 공급사 견적은 내부 수신 후 관리자 또는 담당 영업자가 견적 편집 창의 **검토 완료 · 고객 공유**를 눌러 공유합니다. 내용 변경이나 담당자 변경 시 공유가 해제됩니다.
5. 공급사 결과물의 제출·승인에는 공백이 아닌 설명이 필요합니다. 자유텍스트의 직접 연락처를 자동 차단하는 기능은 없으므로 공유하는 내용을 직접 검토해야 합니다.

가입 화면의 응답 유실 재시도는 같은 `Idempotency-Key`로 처리됩니다. 같은 키에 다른 입력은 409로 거부합니다. 페이지를 새로 열면 별개 요청이므로 네트워크 오류 직후 새 가입 페이지를 열기보다 기존 폼에서 재시도하세요. 브라우저 저장소가 막혀도 가입 결과 ID를 URL로 명시 전달합니다. 이 ID는 데모 선택값이며 인증 토큰이 아닙니다.

기존 DB의 공유 상태 없는 견적은 자동 공개되지 않습니다. 먼저 백업한 뒤 담당 영업자를 지정하고 개별 공유하세요. 기존에 비어 있는 승인 결과물 등 새 검증 규칙을 위반한 자료는 실제 증빙으로 정정해야 합니다. 데이터 초기화를 강제하거나 기존 결과물을 임의로 채우지 않습니다.
