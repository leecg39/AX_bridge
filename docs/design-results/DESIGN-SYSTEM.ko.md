# AX브릿지 디자인 시스템 적용

2026-10-05 · 입력: 사용자가 제공한 `design.md`

## 적용 방향

첨부 문서의 C(한국어 서비스에 맞춘 변형)를 기준으로, 사진 중심 Hero·검색·서비스 탐색·이용 안내의 구조를 AX 구축/교육/인프라 중개 흐름에 적용했습니다. 원본 사이트의 브랜드·실적·고유 폰트를 사용하지 않았습니다. 본 문서는 첨부 자료의 시각 규칙을 적용한 기록이며 원본 사이트의 픽셀 단위 복제를 주장하지 않습니다.

## 사이트 구조

| 주소 | 역할 |
| --- | --- |
| `/` | 새 서비스 홈, 키워드/유형 검색, 카드 탐색, 이용 안내, FAQ |
| `/admin.html` | 기존 운영실, CRM·견적·검수·데이터 관리 |
| `/buyer.html` | 수요기업 포털 |
| `/supplier.html` | 공급기업 포털 |
| `/signup.html` | 서비스/요청 제목을 전달받는 가입 폼 |
| `/consultation.html` | 기존 상담 접수 |

기존 `/#dashboard`, `/#projects/...` 등 운영실 북마크는 `/admin.html`의 같은 해시로 이동합니다. 홈 검색은 6개 서비스 안내 카드의 로컬 필터입니다. 실시간 공급사 검색·외부 추천·계약 체결 기능을 의미하지 않습니다.

## 공통 토큰

`public/tokens.css`가 색상·폰트·간격·모서리·모션의 공통 원본입니다.

| 역할 | 값 | 근거 |
| --- | --- | --- |
| 본문 | #1F2022 | 첨부 문서 |
| 보조/약한 텍스트 | #595C61 / #676D73 | 첨부 문서 |
| 기본/보조/섹션 표면 | #FFFFFF / #F5F6F6 / #FAFAFA | 첨부 문서 |
| 브랜드/일반 링크 | #009FD9 / #0175A3 | 브랜드와 본문 링크의 대비 구분 |
| 주 행동 배경/글자 | #07344A / #B3EBFF | 홈페이지 검색 버튼 규격 |
| 주 행동 hover/active | #094D6B / #052A3A | 첨부 문서 |
| 카드/panel/pill | 16px / 24px / 9999px | 첨부 문서 매핑 |
| Wrap / 검색 최대 너비 | 946px / 588px | 첨부 문서 |
| 폰트 | Pretendard Variable 1.3.9 | 한국어 적용, 로컬 파일 제공 |
| 기본 모션 | 200ms | 기존 효과에 일관 적용 |

홈은 `home.css`, 기존 업무 화면은 `system.css`가 공통 토큰을 사용합니다. 업무 화면의 기존 레이아웃과 상태 구분은 유지하며, 모든 기존 CSS 선언을 제거한 전면 재작성은 아닙니다. 완료/오류/주의 의미색은 별도 토큰으로 구분합니다.

## 컴포넌트와 상태

- **검색**: 이름 있는 입력/서비스 선택/주 CTA. 공백 검증, 검색 결과 수, 빈 결과, 검색 초기화, 입력을 유지한 상담 연결을 제공합니다. 로컬 동기 검색이므로 네트워크 조회용 로딩 상태는 없습니다.
- **탭**: tablist/tab/tabpanel, 선택 상태, roving tabindex, 좌우 화살표·Home·End 지원. 탭 선택 시 이전 검색어를 지우고 해당 서비스 전체를 표시합니다.
- **모바일 메뉴**: 700px 이하에서 표시. aria-expanded, 닫기, Escape, 초점 복귀, 바깥 클릭 닫기를 제공합니다. 탐색 목록이며 모달이 아닙니다.
- **버튼**: primary/secondary, hover/pressed/focus/disabled. 일반 버튼은 pill, 작은 업무 아이콘 버튼은 기존 구조를 유지합니다.
- **카드**: 이미지 내부 확대와 제목·요약·서비스 구분. 전체 카드 링크로 서비스와 요청 제목을 가입 화면에 전달합니다.
- **FAQ**: 네이티브 details/summary를 사용해 키보드로 펼칠 수 있습니다.
- **접근성**: 본문 바로가기, 입력 이름, 결과 live region, 2px focus-visible, reduced-motion, 한글 줄바꿈을 적용했습니다.

## 반응형

- 481px 이하: Hero 사진 212px + 밝은 검색 패널 분리, 제목 30px.
- 482px 이상: 사진 위 제목·검색. 700px까지 제목 40px, 중간 너비 44px, 넓은 화면 48px으로 한국어 길이에 맞춰 조정했습니다.
- 헤더는 701px에서 데스크톱 링크를 표시합니다.
- Wrap 패딩 16→32px, 1011px 이상 0. 서비스 카드는 기본 2열, 701px 이상 3열입니다.
- 운영실은 기존의 넓은 정보 레이아웃을 유지하고 홈의 946px 제한을 강제하지 않았습니다.

## 검증

- 기존 기능 회귀 검사 **81개 통과, 0개 실패**: [로그](regression-tests.log).
- Ego Lite에서 홈 360·390·481·482·700·701·1010·1011·1440px 확인: 가로 넘침 없음, 폰트 로딩 정상, 481/482 Hero 및 700/701 헤더 분기 정상. [기록](responsive-home.json).
- 운영실·수요·공급·가입·상담 화면은 1440/390px에서 확인: 가로 넘침 및 연결 오류 없음. [기록](responsive-product.json).
- “교육” 검색: 교육 카드 2개. 없는 키워드: 빈 결과와 해당 요청을 유지한 상담 링크.
- 오른쪽 방향키로 교육→인프라 탭 이동: 선택·초점 동기화, 인프라 카드 2개.
- 인프라 카드 클릭: 가입 폼 서비스 infrastructure와 요청 제목 “AI 서버·인프라” 전달 확인. 가입 제출은 수행하지 않았습니다.
- 모바일 메뉴 Escape: 닫힘 및 메뉴 버튼으로 초점 복귀 확인.
- 기존 관리자 북마크 이동 확인. 최종 홈 이미지 로딩 실패 0개.

전면 스크린리더 감사와 모든 장치 검증을 수행한 것은 아닙니다. 기존 API·데이터 모델·실제 인증 범위는 변경하지 않았습니다.

### 서비스 카드 이미지 수정
