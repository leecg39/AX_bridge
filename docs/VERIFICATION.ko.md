## 원본 QA와의 차이

프로젝트 원본은 1.0.0이며 AX-QA 보고서 대상 1.1.1과 다릅니다. 원본 API 검사는 25/26 통과입니다. B01의 무키 재전송은 별개 가입으로 유지하고, 회귀 복사본은 실제 UI와 동일한 요청키 계약을 검사합니다. 원본 UI 검사는 결함 재현형이고 현재 없는 KPI 모듈에 의존하므로 통과 개수를 재사용하지 않았습니다. 자세한 변경과 제한은 [QA 반영 내역](QA-IMPLEMENTATION.ko.md)에 기록했습니다.

## 재실행

Node.js 24 이상에서 프로젝트 루트에서 실행합니다.

```sh
npm test
npm start
```

현재 컴퓨터의 기본 node는 v22이고, 이번 검증은 설치된 `/opt/homebrew/opt/node/bin/node` v25.4.0을 사용했습니다. 동일 환경에서는 다음 명령으로 실행할 수 있습니다.

```sh
PATH="/opt/homebrew/opt/node/bin:$PATH" npm test
PATH="/opt/homebrew/opt/node/bin:$PATH" npm start
```

API/VM 테스트는 실제 브라우저 검증과 구별됩니다. 실제 인증·테넌트 격리·운영 보안·전체 접근성·다중 사용자 편집·지원공고 실시간 상태는 검증하거나 구현한 범위가 아닙니다. 자유텍스트 직접 연락처 차단도 제공하지 않습니다.
